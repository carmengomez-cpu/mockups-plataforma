# Mockups plataforma BiotaSmart

Prototipos HTML (datos de ejemplo, anonimizados) de la plataforma para centros, con el **diseño nuevo de la plataforma (v3.18)**.
Descarga el repo y abre cualquier `.html` en el navegador. Todos comparten `tema.css`, `tema.js` y la carpeta `assets/` (fuentes, logo e imágenes).
